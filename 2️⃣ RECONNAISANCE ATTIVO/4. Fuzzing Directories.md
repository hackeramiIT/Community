### Introduzione
Il **fuzzing delle directory**, noto anche come directory brute-forcing, è una tecnica che consiste nell’inviare richieste HTTP automatizzate a un'applicazione web per scoprire directory e file nascosti o non linkati pubblicamente.
Questa tecnica è particolarmente utile per individuare:
- *directory di amministrazione* (`/admin/`)
- *ambienti di test* (`/test/`, `/dev/`)
- *backup dimenticati* (`/backup.zip`, `/index.old`)
- *pannelli nascosti* o *endpoint* non documentati
- *script sensibili* o eseguibili (`.php`, `.aspx`, `.bak`, `.git`, ecc.)

Durante questa fase un attaccante può orientarsi tramite l'[[🔡 Glossario#HTTP Status Code| HTTP status code]] dei risultati.
Il Fuzzing Directories potrebbe esporre servizi nascosti ed a tal proposito si raccomanda di tornare alla sezione[[2. Servizi Online| Servizi Online]].

### Comandi
I tools maggiormente usati sono i seguenti:

```
ffuf -w /usr/share/seclists/Discovery/Web-Content/common.txt -u http://target.com/FUZZ -mc 200,204,301,302,403
```

```
gobuster dir -u http://target.com -w ./directory-list-2.3-medium.txt -t 50 -x conf,config,bak,backup,smp,old,db,sql,aspx,py,rb,php,bhp,cache,cgi,csv,html,inc,jar,js,json,jsp,lock,log,rar,sql.gz,sql.zip,tar,tar.bz2,tar.gz,txt,wadl,zip,xml -o gobuster.txt
```

```
python3 dirsearch.py -u http://target.com -e php,txt,html -w ./raft-small-words.txt
```

```
dirsearch -u http://TARGET_IP -e conf,config,bak,backup,smp,old,db,sql,aspx,py,rb,php,bhp,cache,cgi,csv,html,inc,jar,js,json,jsp,lock,log,rar,sql.gz,sql.zip,tar,tar.bz2,tar.gz,txt,wadl,zip,xml
```
